Identidade do projeto

Nome: Porto Seguro Pet

Tipo: sistema de gerenciamento para ONG de proteção animal

Problema:
Informação desorganizada/descentralizada nos processos da ONG.

Objetivo:
Centralizar e organizar as informações dos processos da ONG.

Usuários:
Administrador
Tutor/adotante

Escopo:
Resgate
Cuidados veterinários
Lares temporários
Adoção
Acompanhamento pós-adoção
Voluntários
Doações
Estoque
Usuários/tutores

Principais funcionalidades:
Cadastro e acompanhamento dos animais
Registro de atendimentos veterinários
Controle de lares temporários
Processo de adoção
Acompanhamento pós-adoção
Cadastro de voluntários e atividades
Registro de doações financeiras
Controle de estoque
Login/acesso dos usuários

Tecnologias já definidas:
Xano
Reflex
Git/GitHub
OpenSpec

Restrições importantes:
Projeto acadêmico
Manter o sistema simples/enxuto
Não criar funcionalidades fora do escopo sem decisão do grupo.
